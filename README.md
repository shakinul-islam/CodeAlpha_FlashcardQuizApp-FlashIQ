# 🧠 FlashIQ - Master Your Memory

**FlashIQ** is a modern, minimalist, and highly interactive Flashcard Quiz application built with Flutter. This project was developed as **Task 1** for the **CodeAlpha App Development Internship** program. It is designed to help users learn and memorize effectively using interactive 3D flip animations and lightning-fast local storage.

## ✨ Key Features

*   **Interactive Quiz Mode:** Beautiful 3D flip animations to reveal answers instantly.
*   **Intuitive Gestures:** Swipe left or right on the flashcards to navigate seamlessly.
*   **Text-to-Speech (TTS):** Built-in audio pronunciation for both questions and answers.
*   **Dark & Light Mode:** Fully responsive theme engine that adapts to user preference.
*   **Card Management:** Full CRUD (Create, Read, Update, Delete) capabilities with smooth slide/fade animations and confirmation dialogs.
*   **Favorite System:** Bookmark difficult cards using the star icon for focused studying.
*   **Progress Tracking:** Live progress bar and dynamic score tracking during quizzes.
*   **Offline First:** Completely offline capability powered by the highly optimized Isar Database.
*   **Responsive UI:** Built with `CustomScrollView` and Slivers to completely prevent keyboard overflow issues on any mobile screen size.

## 🛠️ Tech Stack

*   **Framework:** [Flutter](https://flutter.dev/)
*   **Language:** Dart
*   **State Management:** [Riverpod](https://riverpod.dev/) (`flutter_riverpod`)
*   **Local Database:** [Isar](https://isar.dev/) (NoSQL)
*   **Animations:** Flutter Animate & Explicit Matrix4 Transforms
*   **Typography & Styling:** Google Fonts, Custom Glassmorphism UI
*   **Audio:** Flutter TTS
